# منصة اليوم الوطني السعودي 96 — مدرسة سلمان الفارسي الابتدائية

نسخة أولية فاخرة ومتجاوبة لمنصة المشاركات الوطنية.

## الموجود الآن
- واجهة احتفالية عربية RTL.
- شعار المدرسة المرفق.
- حائط مشاركات تفاعلي.
- بحث وتصفية حسب الفئة.
- نموذج إرسال مشاركة.
- عدادات وإحصاءات.
- تصميم متجاوب للجوال والكمبيوتر.

## ملاحظة مهمة
هذه النسخة تستخدم LocalStorage للتجربة فقط، أي أن المشاركات ليست مشتركة بين أجهزة الزوار.
للنشر الفعلي سنربط النموذج بقاعدة بيانات وStorage مثل Supabase، مع مراجعة واعتماد إداري قبل الظهور العام، ثم نضع مفاتيح البيئة في Vercel.
